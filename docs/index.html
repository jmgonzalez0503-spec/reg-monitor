Regulatory and Legislative Monitor

Automated monitoring of 20 public federal acquisition sources: rules, class deviations, legislation, oversight reports, court decisions, and solicitations.

Maintained by Michael GonzalezLoading results

What this is

A program checks each source on weekday mornings and records any item it has not seen before. This page shows the result of the most recent run.

How to read the status

  • New items: the source was read and something new was found.
  • Nothing new: the source was read and matched the last run.
  • Could not check or Blocked: the source could not be read on this run. This is never reported as "nothing new."
  • Needs API key: the source has an official data feed that requires a free key that is not yet configured.
  • Manual: the source requires a login and is checked by a person.

How sources are read

The program uses official data feeds where an agency provides one. Each source has a backup route where one exists. It identifies itself honestly and follows each site's published rules for automated visitors.

Limits

This page lists public documents. It does not interpret them and is not legal advice. An item recorded as baseline was already published when monitoring of that source began. This is a personal project and is not affiliated with any employer or government agency.
